<objective>
Implement the vLLM proxy layer with model routing, SSE streaming, timeout handling, and OpenAI-compatible error responses. This plan delivers the core request forwarding that connects authenticated, rate-limited clients to the correct vLLM backend.

Purpose: Without this layer, clients cannot reach inference backends. Model routing enables multi-model support. Streaming ensures real-time token delivery. Error handling ensures predictable client behavior.
Output: Working /v1/chat/completions and /v1/completions endpoints that proxy to vLLM with streaming, timeouts, and OpenAI error schema.
</objective>

    Create the proxy, model routing, and error handling infrastructure:

    1. Create src/gateway/models.py — Pydantic schemas matching OpenAI API:
       - class ChatMessage(BaseModel): role: Literal["system", "user", "assistant"], content: str
       - class ChatCompletionRequest(BaseModel): model: str, messages: list[ChatMessage], stream: bool = False, max_tokens: int | None = None, temperature: float = 0.7
       - class CompletionRequest(BaseModel): model: str, prompt: str, stream: bool = False, max_tokens: int | None = None, temperature: float = 0.7
       - class OpenAIError(BaseModel): message: str, type: str, param: str | None = None, code: str | None = None
       - class OpenAIErrorResponse(BaseModel): error: OpenAIError
       - class ModelInfo(BaseModel): id: str, object: str = "model", created: int, owned_by: str = "gateway"
       - class ModelListResponse(BaseModel): object: str = "list", data: list[ModelInfo]

    2. Create src/gateway/proxy.py — vLLM proxy with streaming:
       - MODEL_REGISTRY dict mapping model names to vLLM URLs:
         {"Qwen/Qwen2.5-Coder-32B-Instruct": "http://localhost:8001", "codellama/CodeLlama-70b-Instruct-hf": "http://localhost:8002"}
       - Function: def get_vllm_url_for_model(model: str) -> str
         - Validate model against MODEL_REGISTRY
         - If not found: raise HTTPException(400) with OpenAI error schema (code: "model_not_found")
       - Function: async def proxy_stream(method, url, headers, json_body, timeout) -> AsyncGenerator[str, None]
         - Use httpx.AsyncClient(timeout=timeout) with httpx.Timeout(connect=5, read=300, write=10, pool=5)
         - Use client.stream() to forward request to vLLM
         - Yield chunks via response.aiter_text()
         - Check request.is_disconnected() periodically to cancel vLLM generation on client disconnect (Pitfall 2)
         - Catch httpx.ConnectTimeout -> raise HTTPException(503, "Backend service unavailable")
         - Catch httpx.ReadTimeout -> raise HTTPException(504, "Request timed out during generation")
         - Catch httpx.TimeoutException -> raise HTTPException(504, "Request timed out")
       - Set X-Accel-Buffering: no header on streaming responses (Pitfall 1)

    3. Create src/gateway/errors.py — OpenAI-compatible error handling:
       - Function: def get_error_code(status_code: int) -> str — maps HTTP status to OpenAI error codes
       - Exception handler: async def openai_exception_handler(request, exc) -> JSONResponse
         - Wraps any HTTPException into OpenAIErrorResponse format
         - Handles both string detail and dict detail
       - Exception handler: async def validation_exception_handler(request, exc) -> JSONResponse
         - Wraps RequestValidationError into OpenAI error schema
       - Map status codes: 400->invalid_request_error, 401->invalid_api_key, 403->permission_error, 404->not_found, 429->rate_limit_exceeded, 500->server_error, 503->service_unavailable, 504->request_timeout

    Do NOT hand-roll timeout handling — use httpx.Timeout types. Do NOT buffer streaming responses — use httpx.stream() + StreamingResponse. Do NOT return raw vLLM errors — always convert to OpenAI schema.
