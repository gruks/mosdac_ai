Create src/nlp/normalize.py:

  - SATELLITES: INSAT-3D, INSAT-3DR, INSAT-3A, INSAT-3DS, SCATSAT-1, Kalpana-1

- Create EntityNormalizer class with:
  - normalize(text, entity_type): Normalize entity to canonical form
  - First try exact match (case-insensitive) on known variants

  - Return None if no match (entity stays as-is)
- Add variant mapping for common typos: "INSAT 3D" → "INSAT-3D", "SCATSAT 1" → "SCATSAT-1"
