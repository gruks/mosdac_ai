1. Create GraphRAGPipeline class:
   
   A. __init__():
   - Accept optional Neo4j client (creates if not provided)
   - Initialize VectorRetriever (from plan 01)
   - Initialize GraphRetriever (from plan 01)
   - Initialize ContextCombiner (from plan 02)
   - Initialize Guardrails (from plan 02)
   - Load config from GraphRAGConfig
   
   B. retrieve(query: str) -> dict:
   - Step 1: Check guardrails.detect_injection on query
     - If injection detected, raise ValueError or sanitize
   - Step 2: Execute vector search: vector_retriever.search(query, top_k)
   - Step 3: Execute graph traversal: graph_retriever.traverse(query, depth)
   - Step 4: Combine results: combiner.combine(vector_results, graph_results)
   - Step 5: Sanitize context: guardrails.sanitize_context(combined_context)
   - Return: {context, vector_results, graph_results, injection_detected}
   
   C. query_llm(query: str, llm_client: LLMClient) -> str:
   - Call retrieve() to get enriched context
   - Build secure prompt: guardrails.build_secure_prompt(query, context)
   - Call llm_client.query(enriched_prompt)
   - Return LLM response

2. Handle errors gracefully:
   - Log warnings for retrieval failures
   - Return partial results if one stream fails
   - Use try/except blocks for Neo4j operations

3. Follow patterns from src/rag/pipeline.py for prompt building
