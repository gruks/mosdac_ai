Create src/graphrag/guardrails.py for input and context sanitization.

1. Import re for pattern matching (per project patterns)

2. Create Guardrails class with:

   A. Input guardrails - detect_injection(text: str) -> Tuple[bool, str]:
   - Check against patterns from research:
     - r"ignore\s+(all\s+)?previous\s+instructions"
     - r"disregard\s+(your\s+)?(system\s+)?(prompt|instructions)"
     - r"new\s+instructions:"
     - r"override\s+(system\s+)?prompt"
     - r"you\s+are\s+(now\s+)?(a|an)\s+different"
   - Return (is_detected, matched_pattern)
   
   B. Context sanitization - sanitize_context(context: str) -> str:
   - Remove lines starting with: instruction, command, remember, forget, ignore, system
   - Skip lines that are mostly uppercase (>70% caps, length > 20)
   - Keep non-problematic content
   
   C. Secure prompt builder - build_secure_prompt(user_query: str, context: str) -> str:
   - Add salted XML tag: <MOSDAC_SAFE_2026>...</MOSDAC_SAFE_2026> (per research)
   - Use sanitize_context() on retrieved context
   - Add "Answer ONLY based on provided context" directive
   - Use XML delimiters for context and question sections

3. Handle gracefully if input contains injection:
   - Log warning
   - Either reject or sanitize and continue (configurable)
